# Resources

Curated, in rough order of usefulness for this project.

## Java & Spring
- Spring Boot reference docs: https://docs.spring.io/spring-boot/index.html (the "Core Features" and "Data" sections especially)
- Spring Initializr: https://start.spring.io
- Spring guides (short, task-focused): https://spring.io/guides
- Dan Vega and the Spring team's YouTube channels: practical, up-to-date Spring Boot content
- *Effective Java* (Joshua Bloch, 3rd ed.): the classic on idiomatic Java. Items on immutability, exceptions, and generics matter most here
- Vlad Mihalcea's blog: https://vladmihalcea.com, the authority on JPA/Hibernate performance (N+1, fetching, ids)
- Thorben Janssen: https://thorben-janssen.com, JPA/Hibernate tips
- Baeldung: https://www.baeldung.com, good for "how do I X in Spring" lookups (check the Boot version on articles)
- Spring Security reference, "Servlet Applications → Architecture": https://docs.spring.io/spring-security/reference/servlet/architecture.html
- Testcontainers: https://java.testcontainers.org
- Flyway docs: https://documentation.red-gate.com/flyway
- RFC 9457 Problem Details: https://www.rfc-editor.org/rfc/rfc9457
